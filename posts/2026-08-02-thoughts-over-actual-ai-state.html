Thoughts over actual AI state

February 8, 2026

Interesting and scary times have arrived for the engineer/developer/coder/whatever. I don't think that I have to explain a lot; I think that all the coding agents situation is self explainatory. We are at a point where you can see complete enthusiasts of these new tools. Maximalism of AI, trying at every step to replace a person with an AI agent. Not writing a single line of code. And on the other hand, I see people scared about the future. Thinking that if a computer can write its own code, is just a matter of time for the end of programmers to arrive.

I must say that I have mixed feelings. I'm on the path of learning to become a machine learning Engineer and is something that I feel is challenging and enjoy it. But also I think a lot about the future and how our work is going to change. We can make assemptions but who knows what is going to happen in the future. Right now, and this sentence can change tomorrow, I think that the main ability to be able to still have a job as a software engineer is to know about design systems in order to be able to tell the AI how to implement large-scale develops. Having the ability and the knowledge to design large systems that will work over time, scale when the usage increments, and be prepared to add more functionalities is key right now.

Of course, my words means nothing. There are just thoughts of someone that loves to write code, think code and design code and who, if loses his job and will not longer be able to work coding, expects to write code for the rest of his life. For me, started as a game and is going to end as a game.
