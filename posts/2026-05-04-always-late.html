Always late

April 5, 2026

Strange things are happening in the software development world. Well, not strange, but things are changing really fast lately. Claude code, OpenClaw and a thousand other IA tools, frameworks, LLM, agents, etc etc etc. Too many tools, to many new companies whose domain ends in ".ia". Youtube is full of tutorials, millions and trillions of dollars invested in RAMs so if you want to build a home pc to play Counter Strike is even more expensive than buying the house. And the list keeps going and going and going...

The truth is that I feel that I'm always late. And I mean really late. Just now I'm starting a new project, is going to be open source and if I do it right I think many people will use it. The project itself doesn't matter, but I decided to use it to really use Claude code. I'm starting to look for resources, how to use it well, hoy to be really productive, how to make more effective it's use so I don't spend many tokens when I don't need it, how can I use it in a secure way because I don't want that my keys are travelling thought the internet when Claude code tries to understand the context of the project. And what it feels is that I'm delayed, I'm already late. I see so many people using so many terminals, spending so many tokens, building two or three of four or who knows how many apps at the same time. And also I see the people that is in love with this speed and the people that is scared.

There is a way to be up to date in this period of time? From now the speed is going to be always like this? Or at same point the speed will go down? Or we can go even faster? I don't know. The only thing that I know is that I feel that I'm always late...
