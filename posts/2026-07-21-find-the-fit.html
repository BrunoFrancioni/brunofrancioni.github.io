Find the Fit: Diaries 1

July 21, 2026

Well, I think I'm in loop every year. I'm not able to give a step forward in any direction. Any single path that I want to follow, it ends up not being the ideal or maybe I didn't wanted it at all. But anyways, at this time of the year I made another choise. I want to build something.

I'd never builted something before. I mean, something with some level of hardness and time spent. I feel that in the only ways that I worked really are the work related. So I think is time to develop something for myself. The should be, first of all break the barrier that I feel with myself of never done a real project by my own. That is like a mental barrier that I want to break. And second, I want to use this project to learn things that I never learnt before.

Find the fit is going to be a platform with AI in the backgraound that will allow you to find the clothes that you are searching. With a web scrapping and a AI solution I want to show you all the clothes that fits with your search with the prices and the link to the page to boy them. The main problem that I see is that maybe you are searching for a hoodie, but depending on the web page is called in a different way. There is were I want to implement the solution for that problem using AI. In that way, whis only one way to call a clothe you will be able to get all the results that fits with the kind of it.
